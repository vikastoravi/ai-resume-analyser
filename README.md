# AI Resume Analyser

AI Resume Analyser is a modern web application that helps users analyze resumes using AI-powered features. The platform provides resume scoring, AI-generated summaries, career roadmaps, resume history tracking, and resume download functionality through a clean and user-friendly interface.

---

## Features

- AI Resume Analysis
- Resume Score Generation
- AI-Based Resume Summary
- Career Roadmap Suggestions
- Resume Upload & Download
- Resume History Management
- User Authentication
- Responsive Modern UI
- Profile Management
- Skills & Interests Section
